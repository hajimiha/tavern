# 雾灯谷纪事

一个纯前端、高保真、精细像素风的农场经营与剧情游戏原型。项目使用 React、TypeScript 与 Vite 构建，以本地状态驱动完整经营循环，并加入了本地优先的 SillyTavern 酒馆化数据层与管理界面；不包含后端、鉴权或真实 LLM 网络请求。

## 运行

```powershell
pnpm install
pnpm dev
```

在终端显示的本地地址打开页面。生产构建与测试：

```powershell
pnpm test:run
pnpm build
pnpm preview
```

## 主要体验入口

- 顶部 HUD：日期时间、精力、金币、钓鱼/农耕/挖矿/战斗/魔法等级，以及背包、任务手册、酒馆中枢和设置入口；手机端四项菜单固定在底部快捷坞。
- 苔灯农场：24 个可操作地块，展示作物、成熟时间、浇水、施肥和收获状态。
- 村庄地图：底图与 10 个地点热区位于同一可拖动世界层，支持鼠标、触控、方向键、当前地点定位和视野重置。
- 15 名女性 NPC：按好感阶段上传不同立绘；交谈、赠礼、交易、提交任务和人物档案均有完整界面。
- 经营与剧情：商店买卖、委托板、魔物娘共生牧场、猎人训练、医院、铁匠、魔女商店、图书馆学习。
- 探索玩法：分层矿洞、电梯、安全层挖矿、回合制战斗、五行克制、战败跨日、三段式钓鱼。

## 本地酒馆中枢

点击顶部的记忆图标即可打开“雾灯酒馆中枢”，包含六个完整标签：

- 接口：展示 `TavernApiAdapter` 契约和请求预览；状态固定为 `DISABLED`，不会展示密钥输入或发送网络请求。
- 世界书：两册雾灯谷默认世界书，支持关键词、常驻、注入位置、顺序、递归扫描以及条目增删改。
- 预设：编辑主叙事规则、场景格式和上下文顺序，并切换当前本地预设。
- 角色卡：15 张女性 NPC 角色卡，支持人物设定、首句、示例对白及五个好感阶段的本地立绘上传。
- 会话：保存 NPC 对话楼层、摘要、变量快照与分支来源，支持分支、截断和应用内删除确认。
- 变量：只读展示游戏状态镜像，并编辑当前会话自己的局部变量。

世界书、预设、角色卡、会话和设置均通过 Dexie 保存到浏览器 IndexedDB；初始化只填充空表，不覆盖玩家编辑。

## 对话与未来接口

`src/dialogue/provider.ts` 定义原有剧情流接口，`src/tavern/local-story-engine.ts` 将本地回复转换为正文、行动选项、摘要和变量快照。`src/sillytavern/api-adapter.ts` 仅定义未来可替换的请求契约；当前唯一实现会抛出 `TAVERN_API_DISABLED`，且不会调用 `fetch`。未来接入真实模型时，应在安全的服务端代理中保存密钥并实现同一适配器；本项目按要求没有加入后端或凭据入口。

## 视觉与可访问性

- 三张 WebP 精细像素资产：农场、连续村庄地图和地点场景图集。
- Phosphor SVG 图标，不使用 emoji；应用内 Toast 与内联警告，不调用浏览器原生警告框。
- 模态框支持 Escape、焦点锁定与焦点归还；交互目标不小于 44px。
- 酒馆编辑面板按需加载，支持 `prefers-reduced-motion`，并适配 1440、1024、768 和 375px 宽度。
