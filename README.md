# 雾灯谷纪事

一个纯前端、高保真、精细像素风的农场经营与剧情游戏原型。项目使用 React、TypeScript 与 Vite 构建，以本地状态驱动完整经营循环，并加入了 SillyTavern 风格的角色卡、世界书、预设、会话分支与真实模型接口。项目不包含后端；模型请求由玩家浏览器直接发往所配置的兼容服务。

## 运行

```powershell
pnpm install
pnpm dev
```

在终端显示的本地地址打开页面。生产构建与测试：

```powershell
pnpm test:run
pnpm build
pnpm preview
```

## 主要体验入口

- 顶部 HUD：日期时间、精力、金币、钓鱼/农耕/挖矿/战斗/魔法等级，以及背包、任务手册、酒馆中枢和设置入口；手机端四项菜单固定在底部快捷坞。
- 苔灯农场：新档从第 1 天清晨开始，拥有 500 金币、12 包基础种子和 24 块空地；地块可展示作物、成熟时间、浇水、施肥和收获状态。
- 村庄地图：底图与 10 个地点热区位于同一可拖动世界层，支持鼠标、触控、方向键、当前地点定位和视野重置；拖动后仍可点击建筑并确认前往。
- 15 名女性 NPC：按好感阶段上传不同立绘；交谈、赠礼、交易、提交任务和人物档案均有完整界面。
- 经营与剧情：商店买卖、委托板、魔物娘共生牧场、猎人训练、医院、铁匠、魔女商店、图书馆学习。
- 探索玩法：分层矿洞、电梯、安全层挖矿、回合制战斗、五行克制、战败跨日、三段式钓鱼。

## 酒馆中枢

点击顶部的记忆图标即可打开“雾灯酒馆中枢”，包含六个完整标签：

- 接口：可在本地叙事与远程模型之间切换，内置 DeepSeek，并支持自定义 OpenAI Chat Completions 兼容端点；可测试连接、选择模型并调整温度与最大输出长度。
- 世界书：两册雾灯谷默认世界书，支持关键词、常驻、注入位置、顺序、递归扫描以及条目增删改。
- 预设：编辑主叙事规则、场景格式和上下文顺序，并切换当前本地预设。
- 角色卡：15 张女性 NPC 角色卡，支持人物设定、首句、示例对白及五个好感阶段的本地立绘上传。
- 会话：保存 NPC 对话楼层、摘要、变量快照与分支来源，支持分支、截断和应用内删除确认。
- 变量：只读展示游戏状态镜像，并编辑当前会话自己的局部变量。

世界书、预设、角色卡、会话和设置均通过 Dexie 保存到浏览器 IndexedDB；初始化只填充空表，不覆盖玩家编辑。API 密钥默认只保留在当前浏览器标签页的会话存储中；只有玩家主动勾选“记住密钥”时才会写入本机 IndexedDB。

## 配置真实模型

1. 打开顶部“酒馆中枢”，进入“接口”。
2. 将“对话生成方式”切换为“远程模型”。
3. 选择 DeepSeek 或“自定义兼容接口”，填写 API 地址、模型与密钥。
4. 点击“测试连接”，成功后保存配置。
5. 返回地点，点击 NPC 并选择交谈；角色卡、世界书、预设、历史消息和游戏变量会共同组成模型上下文，模型回复会流式显示并保存到会话楼层。

DeepSeek 默认地址为 `https://api.deepseek.com`，自定义服务需兼容 `GET /models` 与 `POST /chat/completions`。由于这是纯前端原型，目标服务必须允许浏览器跨域请求；若遇到 CORS 拦截，应改用允许浏览器直连的服务，或在未来部署中增加自己控制的安全代理。不要在公共电脑上勾选“记住密钥”。

本地模式仍可离线使用，不会发出模型网络请求。远程模式会把当前 NPC 角色卡、命中的世界书条目、预设、对话历史及必要的游戏变量发送给玩家配置的服务。

## 视觉与可访问性

- 三张 WebP 精细像素资产：农场、连续村庄地图和地点场景图集。
- Phosphor SVG 图标，不使用 emoji；应用内 Toast 与内联警告，不调用浏览器原生警告框。
- 模态框支持 Escape、焦点锁定与焦点归还；交互目标不小于 44px。
- 酒馆编辑面板按需加载，支持 `prefers-reduced-motion`，并适配 1440、1024、768 和 375px 宽度。
