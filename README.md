# 雾灯谷纪事

一个纯前端、高保真、精细像素风的农场经营与剧情游戏原型。项目使用 React、TypeScript 与 Vite 构建，以本地状态驱动完整经营循环，并加入了 SillyTavern 风格的角色卡、世界书、预设、会话分支与真实模型接口。项目不包含后端；模型请求由玩家浏览器直接发往所配置的兼容服务。

## 运行

```powershell
pnpm install
pnpm dev
```

在终端显示的本地地址打开页面。生产构建与测试：

```powershell
pnpm test:run
pnpm build
pnpm preview
```

## 主要体验入口

- 顶部 HUD：日期时间、精力、金币、钓鱼/农耕/挖矿/战斗/魔法等级，以及背包、任务手册、酒馆中枢、全屏和设置入口；点击日期时间可打开“岁时手册”，手机端五项菜单固定在底部快捷坞。
- 苔灯农场：新档从第 1 天清晨开始，拥有 500 金币、12 包春季基础种子和 24 块空地；点击空地可直接选择持有种子播种，地块会展示作物、成熟时间、浇水、施肥和收获状态。
- 村庄地图：底图与 11 个地点热区（含苔灯农场）位于同一可拖动世界层，支持鼠标、触控、方向键、当前地点定位和视野重置；从任意地点都可点击农场或其他建筑并确认前往。
- 15 名女性 NPC：按好感阶段上传不同立绘；交谈、赠礼、交易、提交任务和人物档案均有完整界面。
- 日历与行程：一年 365 天、十二个月、十五位 NPC 生日与分时行程；人物会按工作、休息、阅读、散步和节日活动移动到不同地点，场景在场列表与模型上下文实时同步。
- 岁时与庆典：十二个节日各有三项活动，可在月历中查看生日、节日会场和活动安排；支持选择 NPC 查看全天时间线，也可精确跳到指定时刻或经过若干分钟、小时、天。
- 经营与剧情：商店买卖、委托板、魔物娘共生牧场、猎人训练、医院、铁匠、魔女商店、图书馆学习。
- 探索玩法：分层矿洞、电梯、安全层挖矿、回合制战斗、五行克制、战败跨日、三段式钓鱼。

## 酒馆中枢

点击顶部的记忆图标即可打开“雾灯酒馆中枢”，包含六个完整标签：

- 接口：对话必须使用玩家配置的模型 API。内置 23 个供应商选项，覆盖 OpenAI 兼容、Azure OpenAI、Claude Messages、Gemini/Vertex、Cohere 与 Cloudflare Workers AI 协议；可测试连接，并配置上下文长度、无固定绝对上限的最大回复长度、流式传输、温度、频率惩罚、存在惩罚和 Top P。回复长度需小于上下文长度，客户端会为回复预留预算并裁剪过长提示。
- 世界书：三册雾灯谷默认世界书，其中“雾灯谷·岁时与庆典”完整记录十二节日、生日与人物日程规则；支持关键词、常驻、注入位置、顺序、递归扫描、条目增删改及 SillyTavern JSON 导入/导出。
- 预设：编辑主叙事规则、场景格式和上下文顺序，切换当前模型预设，并导入/导出 SillyTavern 预设 JSON；兼容官方按 `character_id` 分组的 `prompt_order`、Gemini 的 `model` 角色和扩展字段，默认使用角色槽位 `100001`，可查看启用统计并展开编辑各条提示词正文。
- 角色卡：15 张女性 NPC 角色卡，支持人物设定、首句、示例对白及五个好感阶段的立绘上传与仓库内容包发布。
- 会话：保存 NPC 对话楼层、摘要、变量快照与分支来源，支持分支、截断和应用内删除确认。
- 变量：只读展示游戏状态镜像，并编辑当前会话自己的局部变量。

世界书、预设、角色卡、会话和设置均通过 Dexie 保存到浏览器 IndexedDB。API 密钥默认只保留在当前浏览器标签页的会话存储中；只有玩家主动勾选“记住密钥”时才会写入本机 IndexedDB。

### 向所有设备发布酒馆内容

1. 在世界书、预设和角色卡标签完成编辑并保存；角色立绘支持 PNG、JPG、WebP，内嵌单张不超过 512 KB，整包不超过 12 MB。大量立绘建议放入仓库静态资源目录，并在角色卡中使用相对路径。
2. 在角色卡页点击“导出仓库内容包”，得到 `mistvale-content-pack.json`。
3. 用该文件替换仓库中的 `public/content/mistvale-content-pack.json`，提交并推送 GitHub 后重新部署。
4. 内容包版本变化时，各设备会更新包内同 ID 的世界书、预设和角色卡；玩家在本机新建的不同 ID 内容不会被删除。

浏览器不会持有 GitHub 写入令牌，也不会直接修改仓库；仓库主通过正常 Git 提交发布内容，避免把仓库权限暴露给公开玩家。

## 配置真实模型

1. 打开顶部“酒馆中枢”，进入“接口”。
2. 选择模型供应商；界面会自动填入官方地址，并展示该供应商需要的账户、项目、区域或 OAuth 字段。
3. 填写模型名称与 API 密钥或访问令牌。
4. 点击“测试连接”，成功后保存配置。
5. 返回地点，点击 NPC 并选择交谈；角色卡、世界书、预设、历史消息和游戏变量会共同组成模型上下文，模型回复会流式显示并保存到会话楼层。

预设供应商包括 OpenAI、Azure OpenAI、Chutes、Claude、Cloudflare Workers AI、Cohere、DeepSeek、Electron Hub、Fireworks AI、Groq、Google AI Studio、Google Vertex AI、MistralAI、MiniMax、Moonshot AI、NanoGPT、OpenRouter、Perplexity、Pollinations、SiliconFlow、xAI 与 Z.AI；另提供自定义 OpenAI 兼容入口。由于这是纯前端原型，目标服务必须允许浏览器跨域请求；若遇到 CORS 拦截，应改用允许浏览器直连的服务，或在未来部署中增加自己控制的安全代理。不要在公共电脑上勾选“记住密钥”。

项目不再提供本地叙事回退；未配置或连接失败时会在 NPC 会话内阻止生成，并提供进入接口设置的按钮。成功生成时，当前 NPC 角色卡、命中的世界书条目、预设、对话历史及必要的游戏变量会发送给玩家选择的服务。

## 游戏规则设置

顶部设置入口提供八项 0.5–3.0 倍率：经验、好感、收集物掉落、金币收益、作物生长、玩家伤害、敌方伤害与恢复效果；精力消耗另有自由叙事、标准规则和生存压力三档。每项都显示即时计算示例，修改先保留为草稿，点击“应用规则”后才会影响游戏。

完整游戏进度会在每次行动后自动写入版本化 `localStorage` 存档，刷新页面会恢复地点、时间、属性、背包、农田、关系、委托和探索状态。设置页可导出/导入 JSON 存档，也可通过应用内二次确认新建游戏。浏览器清理站点数据或更换设备不会自动同步进度，因此跨设备前应先导出存档，再在另一设备导入。

## 视觉与可访问性

- 三张 WebP 精细像素资产：农场、连续村庄地图和地点场景图集。
- Phosphor SVG 图标，不使用 emoji；应用内 Toast 与内联警告，不调用浏览器原生警告框。
- 游戏通知最多同时显示三条；每条独立显示 2 秒后自动消失，连续相同通知会自动合并，同时保留手动关闭入口。
- 模态框支持 Escape、焦点锁定与焦点归还；交互目标不小于 44px。
- 酒馆编辑面板按需加载，React、图标和本地存储库使用独立缓存分块；支持 `prefers-reduced-motion`，并适配 1440、1024、768 和 375px 宽度。
