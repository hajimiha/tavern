# 《雾灯谷纪事》可拖拽地图与 SillyTavern 酒馆化改造设计

## 1. 目标与边界

本轮改造同时完成三件事：修复地图裁切导致的热点错位、把所有货币文案从“金叶”统一为“金币”、将 SillyTavern 的世界书/预设/角色卡/持久会话/变量/分支能力完整嵌入现有像素经营游戏。

项目继续保持纯前端：不增加服务端、数据库服务器、鉴权或密钥代理。Dexie 仅封装浏览器 IndexedDB；API 连接由用户在本机配置，未配置或请求失败时回退到本地剧情模拟。

## 2. 已确定的方案

采用“嵌入式酒馆中枢”，不新建割裂的独立应用，也不使用通用聊天页面替换农场主舞台。

- NPC 交谈入口打开酒馆化剧情会话，自动绑定当前 NPC 角色卡、地点、好感、共同记忆和游戏变量。
- 顶部设置入口升级为“酒馆中枢”，使用完整模态工作区管理连接、世界书、预设、角色卡、会话和变量。
- 经营、地图、农田、战斗等原有游戏结构保持不变；酒馆系统成为剧情层和记忆层。
- SillyTavern 默认配置：`uiMode='game'`；启用 `maintext`、`option`、`sum`、`vars`、`thinking`、`think`；次 API 关闭；schema-first 关闭。

## 3. 地图交互设计

### 3.1 根因

现有图片使用 `object-fit: cover`，图片被裁切后，绝对定位热点仍按容器百分比计算；图片与热点因此不共享坐标空间。

### 3.2 新坐标模型

`village-map-viewport` 只负责裁切；内部 `village-map-world` 使用固定 1672:941 比例同时承载图片与全部热点。世界层的平移通过一个 `translate3d(x,y,0)` 完成，底图和热点永远一起移动。

初次布局按“contain 后再最小放大到可探索尺寸”计算世界尺寸，确保地图清晰且至少有一个方向可以拖动。偏移量始终钳制在世界边缘，不允许拖出大块空白。

### 3.3 输入方式

- 鼠标/触控：Pointer Events，超过 6px 阈值后进入拖动，避免误触地点。
- 键盘：视口可聚焦，方向键每次移动 56px；Home 重置；`C` 定位当前地点。
- 显式控件：四向移动、定位当前地点、重置全图，所有按钮至少 44px，并使用 Phosphor 图标。
- 地点按钮仍可 Tab 访问；拖动结束后不触发行程弹窗。
- UI 提示实时显示“拖动浏览 / 已定位当前地点”，并通过 `aria-live` 通知键盘定位结果。

## 4. SillyTavern 数据架构

### 4.1 持久化对象

Dexie 数据库保存：

- `Lorebook`：世界书与条目、关键字、优先级、插入位置、启用状态。
- `ChatPreset`：温度、最大输出、系统提示、自定义 Prompts 与 prompt order。
- `CharacterCard`：15 名 NPC 的角色设定、首句、示例对白、绑定世界书和各好感阶段立绘引用。
- `ChatSession`：NPC 维度的多会话、消息、变量快照、分支来源和更新时间。
- `AppSettings`：API 连接、本地回退、激活预设、激活世界书、标签与游戏模式。

首次初始化写入“雾灯谷公共世界书”、默认剧情预设和 15 张 NPC 角色卡；不生成或覆盖用户上传的 NPC 图片。

### 4.2 提示词组装

发送消息时按以下顺序组装：基础系统提示 → 角色卡 → 当前地点与游戏状态 → 命中的世界书条目 → 已启用自定义 Prompt → 经过裁剪的会话历史 → 玩家本轮输入。

世界书匹配支持主关键字、次关键字、递归扫描、优先级和 token 预算。游戏上下文包括日期、时间、精力、金币、技能、好感、任务、地点和共同记忆。

### 4.3 回复解析

流解析器识别默认六类标签：

- `maintext`：显示为剧情正文。
- `option`：显示为可点击行动选项，点击后作为玩家消息提交。
- `thinking` / `think`：折叠显示，不混入正文。
- `sum`：写入会话摘要。
- `vars`：解析变量更新并与当前会话变量合并。

未带标签的普通文本作为 `maintext` 处理。API 未配置、网络失败或格式异常时显示应用内错误与恢复路径，并允许一键切换本地剧情模拟。

## 5. 酒馆化界面

### 5.1 NPC 剧情会话

现有 `DialogueView` 扩展为四区：角色/会话状态栏、剧情正文、选项与消息历史、输入与生成控制。增加会话切换、分支、编辑重生成、删除后续、世界书命中提示和变量摘要；仍保持原先的好感与共同记忆展示。

### 5.2 酒馆中枢

设置按钮打开 `TavernHubModal`，包含六个标签页：

1. 连接：主 API 地址、密钥、模型、本地回退、连接状态。
2. 世界书：启停、导入/导出、新建、条目编辑和关键字配置。
3. 预设：采样参数、系统提示、自定义 Prompt 与顺序编辑。
4. 角色卡：15 名 NPC 卡片、角色提示、首句、示例对白、绑定世界书。
5. 会话：创建、加载、重命名、分支、删除与最近更新时间。
6. 变量：游戏变量只读镜像、会话变量编辑、来源和最后更新时间。

所有删除操作使用应用内确认层；密钥输入默认遮蔽，不在 Toast、日志或导出文件中输出明文。

### 5.3 视觉语言

沿用深苔绿、夜蓝黑、铜金和羊皮纸文字；吸收 UI/UX Pro Max 推荐的高密度 Bento 层级，不采用通用 AI 紫粉配色。世界书用“黄铜索引片”、角色卡用“档案卡”、会话分支用“丝线谱系”表达酒馆语义，并继续使用 Phosphor 图标与像素描边。

## 6. 货币文案

生产源码、默认数据、Toast、aria-label、测试和文档中的“金叶”全部替换为“金币”。内部 `money` 字段不改名，避免无收益的数据迁移。

## 7. 错误与降级

- IndexedDB 不可用：切换到本次页面内存模式并显示持久化不可用提示。
- 导入文件无效：在文件控件附近显示原因，不写入半成品数据。
- API 连接失败：保留玩家消息为待重试状态；提供重试和本地模拟两个动作。
- 流式中止：保留已生成正文，消息标记为“已停止”。
- 世界书或预设为空：自动启用内置默认项，不阻断对话。
- 地图尺寸变化：ResizeObserver 重新钳制偏移，不重置用户当前浏览位置。

## 8. 性能与可访问性

- SillyTavern 管理界面按模态打开后再加载，避免首屏解析全部编辑器组件。
- 地图拖动只更新 transform，并通过 `requestAnimationFrame` 合并高频 Pointer 更新。
- 长会话仅渲染可见窗口附近消息或限制首屏历史数量。
- 所有图标按钮带中文 `aria-label`；标签页使用 `role=tablist/tab/tabpanel`。
- 拖拽拥有键盘和按钮替代；模态保留 Escape、焦点锁定与焦点归还。
- reduced-motion 下关闭地图惯性、选项入场和流式光标动画。

## 9. 测试与验收

- 单元测试：偏移钳制、拖动阈值、世界书匹配、提示词顺序、变量合并、流标签解析、导入默认值。
- 组件测试：地图指针拖动/键盘移动/重置；金币文案无“金叶”；酒馆中枢六标签；创建/加载/分支会话；选项提交和本地回退。
- 构建检查：TypeScript、Vitest、Vite 全通过。
- 浏览器检查：1440×900、1024×768、768×1024、375×812；地图热点随世界层同步移动，四方向均可到达，页面无水平溢出，酒馆模态不出屏，控制台零错误。
