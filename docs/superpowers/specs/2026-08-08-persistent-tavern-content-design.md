# 雾灯谷持久酒馆与内容生产设计规格

## 目标

在不增加后端的前提下，使当前前端具备可持续游玩、可移植内容生产和完整模型参数控制：刷新后恢复游戏进度；仓库主可通过 GitHub 更新默认世界书、预设与角色立绘；玩家仍可保留本机草稿；所有模型对话继续从浏览器直连已配置 API。

## 采用方案

采用“仓库默认内容包 + 浏览器本机覆盖层 + 可移植 JSON”的双层架构。

- 仓库默认内容包位于 `public/content/mistvale-content-pack.json`，包含版本、世界书、预设和角色卡覆盖项。仓库主可以直接在 GitHub 修改该文件，或把前端导出的内容包提交到该路径；静态立绘也可使用 `public/portraits/` 下的仓库路径。
- Dexie 继续保存当前设备的世界书、预设、角色卡、立绘和会话。编辑器中的修改是本机草稿，不会声称能从浏览器直接提交 GitHub。
- 单册世界书和单个预设支持 SillyTavern 兼容 JSON 导入/导出；角色编辑器继续支持图片上传，并增加类型、大小反馈。完整内容包支持导出，供仓库主提交。
- 首次启动以代码内置内容为基础，再应用仓库内容包覆盖；已有本机内容不被静默清空。界面明确显示“仓库默认”和“本机草稿”的职责。

未采用的方案：浏览器直接写 GitHub。该方案必须让玩家提供 GitHub Token 或增加 OAuth/后端代理，会扩大权限和泄露风险，也违反当前纯前端范围。另一个未采用方案是只保存本机文件，因为它无法让仓库默认内容跨设备分发。

## API 参数模型

`TavernApiConfig` 统一为：

- `contextLength`：客户端提示词预算，正整数；组装请求时保留系统消息和最近对话，并从旧到新裁剪历史。
- `maxResponseLength`：最大回复长度，正整数且界面不设上限；旧 `maxTokens` 自动迁移。
- `streaming`：控制真正的 SSE/非流式请求路径，而非仅影响显示。
- `temperature`：0–2。
- `frequencyPenalty`、`presencePenalty`：-2–2。
- `topP`：0–1。

协议映射：OpenAI 兼容协议接收全部采样参数；Claude 使用 `max_tokens`、`temperature`、`top_p`；Gemini/Vertex 使用 `generationConfig`；Cohere 使用其 v2 字段；Cloudflare 仅发送通用且模型普遍支持的字段。界面会说明部分供应商会忽略不支持的惩罚参数。

移除“恢复官方地址”按钮。切换供应商仍会装载该供应商预设地址，玩家可随后自由修改。

## 地图与会话修复

- 为 `farm` 增加与底图左下农田一致的 `mapPosition`，不再从热区和手机地点列表过滤。玩家位于其他地点时，农场与所有地点一样出现悬停边框、行程卡和“确认出发”。
- 当前地点仍显示热区；选择当前地点时确认按钮变为不可用的“已在此处”，避免重复消耗时间。
- 对话面板改成三段式：固定头部、唯一可滚动的会话主体、固定底部编辑器。消息、选项和错误提示都进入滚动主体；新回复后自动滚到末尾，编辑器始终可达。
- 手机端使用 `100dvh` 边界、`min-height: 0`、`overscroll-behavior: contain`，避免滚轮/触控滚动被外层页面吞掉。

## 自动存档

建立版本化 `GameSaveEnvelope`，使用 localStorage 自动保存游戏状态。保存内容包括时间、地点、精力、金币、技能、背包、农田、关系、任务、矿洞、战斗和工具；不保存通知、当前模态框和临时选择。

- `GameProvider` 无显式 `initialState` 时读取自动存档；测试或嵌入方传入 `initialState` 时保持完全隔离。
- 每次状态变化后自动写入；损坏或旧结构无法迁移时安全回退到新档，不让页面崩溃。
- 游戏设置中增加存档状态、导出、导入和新建存档。导入/重置使用应用内确认与通知，不使用浏览器 `alert/confirm`。

## 全屏与可访问性

- HUD 右上角增加 44px 全屏按钮，使用 Phosphor 图标，监听 `fullscreenchange` 同步“进入/退出全屏”状态；浏览器不支持时禁用并给出标签说明。
- 所有新增按钮和文件输入具有唯一描述性 ID；数值输入使用 `inputMode="numeric"` 或 `decimal`。
- 动画延续 150–300ms 铜金微交互，并尊重 `prefers-reduced-motion`。
- 验证视口：1440×900、1024×768、375×812，另检查手机横屏；不得出现横向滚动，编辑器和确认按钮必须可触达。

## 性能边界

- 自动存档只序列化小型游戏状态；立绘和会话继续留在 IndexedDB。
- 文件读取按需触发，不把内容包编辑器提前加载到主场景。
- 地图保持单张压缩 WebP 与 CSS 热区，不增加额外位图层。
- 大型立绘导入前限制文件类型和大小，并在内容包导出时提示文件体积。
